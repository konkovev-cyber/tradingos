# VOL-001: Volatility Compression Breakout

## Hypothesis

Периоды низкой волатильности (сжатие) предшествуют периодам высокой волатильности (расширение). Вход в момент расширения после сжатия даёт движение в направлении пробоя.

## Market Logic

- Рынок цикличен: expansion → contraction → expansion
- Сжатие = накопление энергии
- Пробой = высвобождение энергии
- Контрагенты: те, кто торгует против breakout (fading)

## Data Requirements

- OHLCV
- ATR (14) + ATR percentile (50 bars)
- Bollinger Bands width
- Donchian Channel (20)

## Entry Logic

```
Условия:
1. ATR percentile < 20 (compression)
2. BB width < 20-period low
3. Price breaks Donchian 20 high or low

Вход:
- LONG: close > Donchian 20 high
- SHORT: close < Donchian 20 low
```

## Exit Logic

```
- Trailing SL: ATR × 3 (chandelier exit)
- Or: close opposite side of ATR channel
```

## Failure Modes

| Mode | Cause | Detection |
|------|-------|-----------|
| False breakout | Price returns inside range | Close inside Donchian next bar |
| Whipsaw | Multiple breakouts | Consecutive false signals |
