# Direction-Edge Research — отчёт (2026-08-29, v1)

## Гипотеза
Свечная структура даёт статистически предсказуемое краткосрочное направление движения. Если да — execution engine (лимитный вход + динамическое управление) имеет смысл. Если нет — никакой exit/SL-TP не исправит.

## Данные
- 27 символов (18 крипто + 9 токенизированных акций), ~3000 H1-баров каждый ≈ **125 дней**.
- 78 656 наблюдений закрытых H1-баров с признаками как в manual_scanner.
- Forward return от close к close на +1/+2/+5/+10 H1.
- Измерение: взвешенная средняя fwd return + t-статистика. Без издержек.

Положительный fwd10 — это **долгосрочный дрифт цен** (период роста), а не edge: fwd1 (то, что реально ловит вход) незначим.

**SCANNER_LIKE_LONG не показывает положительного edge на ближних горизонтах** — при дневном дрифте +0.07% (fwd10) сетап-лонг идёт в ноль/минус.

### 3. Стабильность по времени — ГЛАВНЫЙ ФИНДИНГ
Знак «edge» **флипается между хронологическими сегментами**:

| сегмент | H1_DOWN SHORT fwd5 | RSI<40 LONG fwd5 |
|---|---|---|
| SEG1 (старший) | **−0.12% (t=−7.8)** ✅ работало | −0.12% (t=−5.4) |
| SEG2 | **+0.11% (t=+6.8)** ❌ убыточно | +0.23% (t=+10.1) |
| SEG3 (свежий) | −0.01% (t=−0.8) | +0.01% (t=0.6) |

Направленный «edge» в одних сегментах = убыток в соседних. Это **режим-зависимость/дрифт, а не стабильный edge**.

### 4. Время суток
- SCANNER_LIKE_LONG: 08–16 UTC fwd5 +0.069% (t=2.6), 16–24 UTC **−0.109% (t=−5.9)**.
- Торговые часы акций дают разный знак у одного и того же сетапа — ещё один признак нестабильности.

## Вывод
**На H1-масштабе простые свечные признаки (EMA-структура, RSI, dist-to-EMA, объём, pullback-зрелость) НЕ дают стабильного предсказуемого направления.** Всё, что выглядит значимым, объясняется дрифтом и режимом; знак edge флипается между сегментами.

Текущие LONG-сетапы сканера в среднем дают fwd1 ≈ 0..−0.005% — т.е. **нет доказанного преимущества** на горизонте входа.

## Что это НЕ доказывает
1. **Entry quality**: не проверены лимитные зоны (вход на откате может иметь другой профиль, чем close-to-close H1).
2. **M15-масштаб**: 15-минутные структуры (интрабар) не проверены.
3. **Режим-кондиционирование**: возможно, edge существует только в определённых состояниях волатильности — нужен условный анализ, а не безусловный.

## Следующие шаги (по согласованию, БЕЗ изменения production)
- M15-исследование: forward return на +1/+4/+8/+16 M15-баров (~0.25–4ч).
- Entry-качество: fill probability и forward return ПОСЛЕ касания лимитной зоны (по тикам/интрабару), для LIMIT-контура.
- Условный анализ по режимам волатильности (ATR-квантили).

# Дополнение v2: M15-масштаб (2026-08-29)

## Данные
- 27 символов, ~6000 M15-баров каждый ≈ **62 дня**.
- 160 772 наблюдения, forward return на +1/+4/+8/+16 M15 (15м/1ч/2ч/4ч).

## Результаты

### SCANNER_LIKE сетапы (то, что даёт сканер)
| сетап | fwd+1(15м) | t | fwd+4(1ч) | t |
|---|---|---|---|---|
| SCANNER_LIKE_LONG | −0.0004% | −0.3 | +0.0009% | 0.4 |
| SCANNER_LIKE_SHORT | +0.0023% | 1.7 | +0.0016% | 0.6 |

LONG стабильно ~0 по всем 3 сегментам (0.0009 / −0.0012 / −0.0007). **Ноль edge.**

### Единственный статистически значимый сигнал: mean-reversion
RSI<40 (перепроданность) на M15: fwd+1 = **+0.011%** (t=5.5), fwd+4 = +0.042% (t=11.0), n=28099.

Но: round-trip издержки Bybit ≈ **0.075%** (maker 0.02% ×2 + запас на slippage) — значимый сигнал в 7 раз меньше издержек. **NET < 0.**

## Итоговый вывод
1. **Ни H1, ни M15: простые свечные признаки не дают стабильного направленного edge, переживающего издержки.**
2. SCANNER_LIKE LONG/SHORT: fwd1 ≈ 0 → нет доказанного преимущества перед случайным входом.
3. RSI<40 на M15 — реальный mean-reversion эффект (значим), но экономически микроскопический (0.011% vs 0.075% издержек).
4. Долгосрочный дрифт (+0.04%/4ч) — рост рынка, не условный edge.

Это прямой ответ на фундаментальный вопрос: **в текущем feature-space свечи НЕ дают предсказуемого краткосрочного движения, которое покрыло бы издержки.** Строить execution engine (лимитные зоны / динамический SL-TP) на этом основании преждевременно.

## Что осталось непроверенным (кандидаты на следующий цикл)
- Entry-качество лимитных зон: forward return ПОСЛЕ касания зоны (fill-условный), а не от закрытия бара.
- Условный анализ по режимам волатильности (ATR-квантили intraday).
- Мультиинструментальная дисперсия: RSI<40 mean-reversion — на каких символах, а не в среднем.
