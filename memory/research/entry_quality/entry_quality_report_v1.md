# Entry-Quality Research V1 — отчёт (2026-08-29)

## Вопрос
Может ли правильно выбранная LIMIT-зона улучшать экономику сделки за счёт лучшей
цены входа, ДАЖЕ если направление почти непредсказуемо (direction edge ≈ 0)?

## Данные
- 27 символов (крипто + акции), M15, ~62 дня, 161 204 бара.
- 61 699 scanner-like кандидатов (строгое направление + momentum + dist-EMA20 ≤ 0.35%).
- Зоны фиксированы заранее: ±0.10/0.20/0.30/0.50% и 0.25/0.50/0.75/1.00×ATR.
- touch = экстремум бара в окне 16 M15 (4ч); консервативно: forward от закрытия
  бара касания; горизонтальный exit 15м/1ч/2ч/4ч (SL/TP НЕ моделировались).
- PnL нормализован по стороне; артефакты данных (|fwd|>50%) исключены (42 шт).
- Fees: maker 0.02%×2, taker 0.055%×2 + cost stress ×1.5/×2.

## Вывод
1. **Price improvement существует**: лимитка даёт вход на 0.10–0.50% лучше маркета
   при касании и срезает издержки (maker vs taker) → NET/all −0.11% (маркет)
   → −0.01…−0.04% (лимит). Разница ≈ +0.08–0.10 п.п. у лимитки.
2. **НО это не создаёт положительного NET**: при direction edge ≈ 0 вся экономика
   сводится к (−издержки). Глубокие зоны (0.50%, 1.0 ATR) ближе к нулю только
   потому, что реже касаются → реже платят издержки, а зарабатывать не на чем.
3. **Пропущенные возможности не компенсируют**: NET if market-entered на
   non-touch кандидатах ≈ 0 (−0.015%); лимитка не теряет edge на пропуске,
   потому что edge ≈ 0.
4. **При +50%/+100% издержек всё уходит глубже в минус.**

**FINAL: REJECT для ветки «лимитный вход сам по себе создаёт NET».** Улучшение
цены входа реально (это измеримо), но при нулевом направленном edge не переводит
экономику в плюс. Горизонтальный exit на 15м–4ч не меняет картину.

## Что это НЕ доказывает
- Exit-модели (динамический выход по состоянию рынка) — здесь был только
  фиксированный горизонт; они отложены до появления доказанного entry edge.
- Условные стратегии: возможно, есть подмножества (режимы/символы), где
  направление ≠ 0; в среднем по вселенной — нет.
